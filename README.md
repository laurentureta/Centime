# Centime

Heures, heures sup, congés et salaire net — au centime près. Application iPhone (PWA) en un seul fichier HTML.

- Calendrier prérempli avec l'horaire du contrat, saisie au jour le jour ou pointage arrivée/départ
- Heures sup par semaine civile (+25 % de 35 à 43 h, +50 % au-delà)
- Bulletin de paie reconstitué ligne par ligne (cotisations, CSG/CRDS, tickets resto, net imposable)
- Solde de congés payés, estimation de fin de contrat
- Sauvegarde optionnelle des données dans un dépôt GitHub **privé**

Le moteur de calcul est contrôlé sur un bulletin réel : 12 montants sur 12 identiques au centime.

## Installer sur iPhone
1. Ouvrir `https://laurentureta.github.io/Centime/` dans Safari
2. Partager → **Sur l'écran d'accueil**

Les saisies restent sur le téléphone (ou dans ton dépôt privé si tu actives la sauvegarde GitHub) : rien n'est publié ici.
